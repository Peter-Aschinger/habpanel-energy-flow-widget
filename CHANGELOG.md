# Changelog

## v3.4
- No delay when scrolling the dashboard: the widget no longer scrolls by itself (new setting scrollInside to re-enable)

## v3.3
- Smoother scrolling on smartphones: no fill animation, own graphics layer, smaller chart filter areas

## v3.2
- Number settings now have numeric defaults, so they are shown in the HABPanel settings dialog

## v3.1
- Support for items with units (openHAB 3 and newer): unit is split off, W/kW and Wh/kWh/MWh are converted
- +/- buttons send the minimum SoC with the item's unit

## v3.0
- First public version: all items via settings, German/English labels, history charts for PV and grid, hideable tiles, Victron-style fill
